This tool is designed to visualize the dispersion radius and target area of all artillery pieces in Steel Division 2.



Multiple artillery pieces in the game are used by different units. For example, the mortar "M1" is used by both the mortar team "MORTAR 81mm" and the self-propelled mortar "M21 MMC 81mm". However, this does not affect dispersion when no radio is used. The names of the checkboxes are only example unit names; when hovering over a checkbox, the name of the artillery piece itself is shown along with additional key stats. To make it easier to find an artillery piece that is not used as an example, you can use the search bar. The name of each artillery piece can be found in-game, between the image and the ammunition information.



The program can be easily used by executing the sd2\_artillery.exe file, ensuring that the data.json file is in the same folder. Alternatively, you can run the main.py file using Python with the required packages installed.



Please note that special characters such as “Ș” in REȘITA or “ö” in Mörser are replaced with their basic letters (S and o). Additionally, some names may contain grammatical errors or spacing issues. In general, any errors in the data can be directly corrected by modifying the JSON file.
